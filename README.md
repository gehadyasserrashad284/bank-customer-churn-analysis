# Bank Customer Churn Analysis

## Project Overview
This project analyzes bank customer data to identify patterns associated with customer churn. The dataset was cleaned, analyzed, and visualized to extract meaningful business insights.

## Dataset
The dataset contains 10,000 customer records and 12 features, including:
- Credit Score
- Country
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Credit Card
- Active Membership
- Estimated Salary
- Churn

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Extract
2. Clean & Transform
3. Analyze
4. Visualize

## Data Cleaning
The data was checked for:
- Missing values
- Duplicate records
- Duplicate customer IDs
- Invalid categorical values
- Invalid numerical values
- Suspicious salary values

## Analysis
Customer churn was analyzed based on:
- Country
- Gender
- Age Group
- Number of Products
- Active Membership
- Credit Card
- Balance
- Credit Score
- Tenure

## Key Insights
- Overall churn rate is approximately 20.37%.
- Germany has the highest churn rate at approximately 32.44%.
- Female customers have a higher churn rate than male customers.
- Inactive members have a higher churn rate than active members.
- Customers aged 51–60 show the highest churn rate.
- Customers with 3 or 4 products show very high churn rates, but these groups contain relatively few customers.
- Customers with balances above 200K show high churn, but this group contains only 34 customers.
